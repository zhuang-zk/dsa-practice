## 每题怎么写

1. 在对应周目录下建文件，命名用 `题号_英文名.py`
2. 每个文件包含三部分：思路注释、函数实现、本地自测
3. 先在本地跑通，再去力扣提交
4. 允许看题解，但看完必须合上从空白文件重写一遍，否则等于没做

```bash
python week01/27_remove_element.py      # 跑本地自测

git push
```

提交说明写清楚做了什么，不要写 update。
